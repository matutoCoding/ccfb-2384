# 营造 · 参数化木构建模工具

浏览器端参数化古建筑木构建模:斗拱复原、梁架装配。TypeScript + WebGL2,**不依赖任何现成 3D 引擎**(渲染器、数学库、几何内核全部手写)。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
```

## 四个页面

| 页面 | 功能 |
|---|---|
| 构件库 | 八等材模数切换、宋尺换算、构件尺寸随材等联动 |
| 斗拱编辑 | 出跳数(四~八铺作)、昂形(杪/下昂/上昂)、真昂/假昂、逐跳计心偷心、双杪 |
| 梁架装配 | 开间/进深/柱网参数、拖拽吸附柱网、撤销重做(Ctrl+Z/Y) |
| 渲染设置 | SSAO、阴影、木纹、曝光、剖切平面、glTF / 立面 SVG 导出 |

## 八项核心需求的实现位置

1. **材分联动** — `src/geom/caifen.ts` 八等材模数;所有几何以「分°」为单位生成,改材等只改换算系数,装配关系不变,全场景重算。
2. **截面放样** — `src/geom/loft.ts`:相邻环共享顶点(焊接)+ 面积加权法线平均,卷杀曲面平滑无接缝;`src/geom/section.ts` 四瓣卷杀 / 月梁式连续曲线。
3. **铺作参数化** — `src/geom/dougong.ts`:出跳 1~5、昂形、计心偷心;斗拱交接(榫卯)位置由同一套模数推出,自动对齐。
4. **梁架装配** — `src/geom/frame.ts`:开间进深为唯一参数源,改动即整体重算;`src/state/store.ts` 命令模式撤销/重做;视口拖拽吸附柱网(`src/ui/viewport.ts`)。
5. **视口交互** — `src/engine/camera.ts` 轨道相机;剖切平面(片元 discard);拾取 ID 图边缘检测做选中描边(`src/engine/shaders.ts` OUTLINE_FS)。
6. **渲染** — 手写 PBR(GGX)+ 方向光 PCF 阴影(场景静态时阴影贴图缓存不重烘)+ 半分辨率 SSAO(可开关)+ 程序化木纹(年轮 + 纤维噪声)。
7. **工程持久化** — `src/state/db.ts`:IndexedDB 存工程,每次保存自动落版本快照,可回滚;JSON 导入导出。
8. **导出** — `src/export/gltf.ts`:GLB(单位米,节点 scale 做分°→米换算,查看器中即实物尺寸);`src/export/svg.ts`:正立面凸包投影 + 尺寸标注链(开间/通面阔/柱高/通高,毫米)。

## 性能设计(千级构件 50fps+)

- 同类构件共享一份几何,**GPU 实例化**渲染:整个场景只有十几个 draw call。
- 阴影贴图按脏标记重烘,静态视角零开销;SSAO 半分辨率。
- 改参数只重算受影响的几何缓存(`partGeometry` 按 类型@材等 缓存)。

## 单位制

内部一律「分°」;`材等 × 宋尺` 决定 1 分° 的毫米数;glTF 导出换算为米。SVG 标注以毫米出图。
